White Label Login Integration Examples

This page demonstrates different ways to integrate with hostbuddy.ai white-label login from c.acental.com

Method 1: Direct URL Redirect

Redirect users directly to the white-label login URL with credentials as parameters.

URL Format: https://hostbuddy.ai/white-label-login?email=EMAIL&password=PASSWORD

Method 2: POST API Request

Send credentials via secure POST request to the API endpoint.

POST https://hostbuddy.ai/api/login Body: {"email": "...", "password": "...", "whiteLabelDomain": "c.acental.com"}

Method 3: Iframe Integration

Embed the login in an iframe and communicate via postMessage.

iframe.contentWindow.postMessage({type: 'WHITE_LABEL_LOGIN', credentials: {...}}, '*');

Method 4: Form Submission

Traditional form POST to the login endpoint.
